## Tie-breakers

- **Brief says "premium"**: dark-luxe if evening/luxury, editorial-serif if
  daytime/craft. Price point decides.
- **Brief says "bold"**: acid-rave if youth/culture, industrial-brutalist if
  B2B/technical, neo-brutalist-pop if playful/consumer.
- **Brief says "minimal"**: ma-japanese if luxury/craft, swiss-rational if
  data/systems, soft-minimal if product/SaaS.
- **Brief says "fun"**: neo-brutalist-pop if friendly, y2k-chrome if
  nostalgic, acid-rave if rebellious.
- **No clear signal**: default to **soft-minimal** (safest) or **editorial-serif**
  (most distinctive). State that you defaulted and why.

## Anti-patterns

- Don't blend two DNAs "to be safe". One DNA, committed, beats two DNAs
  compromised.
- Don't pick by personal preference. The brief decides.
- Revisit the choice if the ANTI-SLOP review surfaces more than two warnings —
  a wrong DNA forces slop-shaped compromises.
