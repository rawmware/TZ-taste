Data validation you can actually read.

Lattice is a dependency-free validation library for Python and TypeScript. Schemas are plain objects, errors are plain sentences, and the whole thing fits in your head by lunch.

signup.py
from lattice import schema

user = schema({
    "name": str.min(2),
    "email": email(),
    "age": int.between(13, 120),
})

result = user.validate(form_data)
# result.ok → True / False
# result.errors → ["age must be between 13 and 120"]
$pip install lattice

A note on scope

Questions we hear weekly

Short answers. Longer ones live in the guides above.

Is Lattice really dependency-free?−

Yes. The install is one package with zero transitive dependencies — we vendor nothing and require nothing. That's a design constraint we test in CI, not a marketing claim.

Does it work with my framework?+

Lattice validates plain data, so it works anywhere: Express, FastAPI, Django, Next.js, or a script. There are thin adapters for React Hook Form and Pydantic-style decorators, maintained in the contrib repo.

How do I report a security issue?+

Email security@lattice.dev — please don't open a public issue. We acknowledge within 48 hours and publish a fix timeline, not just a patch.

Can I use it commercially?+

Yes. MIT license, no contributor license agreement, no dual-license trap. Companies from two-person startups to public utilities run it in production.
