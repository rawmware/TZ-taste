mason — zsh

The scaffolding CLI that respects your setup.

mason generates project scaffolding from templates you actually control — no 400-file dumps, no mystery configs, no "opinionated" anything. Open source, MIT licensed, 48 templates maintained by people who ship.

Install mason

install

One line. No package-manager drama, no post-install survey, no telemetry. (We don't phone home. Check the source.)

# macOS / Linux
curl -fsSL https://mason.dev/install.sh | sh

# or, if you prefer to see what you're running
brew install mason-cli        # homebrew
cargo install mason           # rust
npm i -g @mason/cli          # npm

commands

Eight commands. You'll use three daily and forget the rest exist — which is the point.

mason newScaffold a project from any template. Interactive, skippable, resumable.
mason addGraft a template into an existing project without clobbering your files.
mason listShow installed templates with versions, sources, and last-used dates.
mason diffPreview exactly what a template would change before it touches disk.
mason pinLock a template version per project. Upgrades are always opt-in.
mason makeTurn your current project into a template. Share it or keep it.
mason doctorDiagnose your setup: runtimes, versions, PATH. Fixes what it can.
mason --helpThe manual. Written by humans, with examples that run.

why mason

Every scaffolding tool promises speed. mason promises something rarer: you stay in charge.

other tools mason +----------+ +----------+ | template | | template | | (blob) | | (recipe) | +----+-----+ +----+-----+ | | v v +----------+ +----------+ | 400 files| | 12 files | | "trust | | + a diff | | me" | | you read | +----------+ +----------+
  • Diffs before writesmason diff shows every file it would create, change, or skip — before anything happens. No surprises in your repo.
  • Templates are recipes, not blobsA mason template is a readable script with variables and conditions. Fork it in an afternoon; understand it in an hour.
  • Zero lock-inOutput is plain files. Uninstall mason tomorrow and everything still builds. We consider that a feature, not a bug.
  • Fast enough to forgetCold start in 40ms. Scaffolding a full-stack app takes under two seconds — most of it is your disk.
