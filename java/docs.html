Docs / Quickstart

Send your first route in five minutes.

Meridian is a routing API for delivery fleets. This page takes you from an empty project to a live optimized route — no sales call required.

1. Get a key

Sign up and copy the test key from your dashboard. Test keys start with mk_test_ and can route up to 1,000 stops a day — plenty for development.

# .env — never commit this file
MERIDIAN_KEY=mk_test_4f8a2c1d9e

2. Create a route

Post your stops. Meridian returns the stops in visit order with drive times attached. The whole round trip here takes under a second.

curl -X POST https://api.meridian.example/v1/routes \
  -H "Authorization: Bearer $MERIDIAN_KEY" \
  -d '{"stops":[{"lat":43.66,"lng":-70.25},{"lat":43.70,"lng":-70.30}]}'
Heads upCoordinates are latitude first. We know — half the industry does it the other way. The API rejects anything that looks like a swapped pair and tells you.

3. Go live

Swap the test key for a live one when you're ready. Nothing else changes — same endpoints, same shapes, real billing per routed stop.

Why five minutes? Because we timed twelve new users. The slowest took 6:40; they were making coffee.

On test data: use your real addresses in test mode. Test routes are deleted nightly and never billed.
