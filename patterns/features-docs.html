What it does, with receipts.

Capture webhooks

Point any service at your endpoint. Payloads land parsed, timestamped, and searchable.

copy
curl -X POST https://api.example.com/v1/hooks \
  -H "Authorization: Bearer $KEY" \
  -d '{"event":"order.paid"}'

retries for 24h · signs every payload

Query the log

Every event is queryable the second it arrives. No pipeline to babysit, no warehouse bill.

copy
events.where(type = "order.paid")
  .group(by: "region")
  .sum("total")

sql + a friendlier dialect · 90-day retention

Ship the alert

When a query crosses your threshold, the alert goes where your team already looks — Slack, PagerDuty, or a plain webhook you own.

copy
alert "big-order" when sum(total) > 5000
  -> slack("#ops") + webhook($URL)

dedupe built in · quiet hours respected · test mode included
