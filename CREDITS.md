# Credits & Lineage

TZ-taste is original work, but no taste develops in a vacuum. This file names
the shoulders it stands on — for **principles**, never copies. Nothing here is
reproduced: no code, no layouts, no assets taken from anyone.

## Direct lineage

- **[taste-skill](https://github.com/Leonxlnx/taste-skill)** (MIT) — the anti-slop
  agent skill that proved taste could be written as instructions. TZ-taste's
  dials, pre-flight checks, and blocklist format learn from its structure.
- **[ThreeUI Community](https://github.com/MengTo/threeui)** (MIT) — the model for
  a live component catalog: browse, preview, copy source. Our pattern library's
  UX follows its spirit.
- **[agent-design-taste](https://github.com/aievolutionpl/agent-design-taste)** (MIT) —
  style-DNA routing, context profiles, and the idea of scoring taste.
- **[SceneAI](https://sceneai.art)** (paid) — the premium prompt library that
  showed the demand. TZ-taste exists as its free alternative.

## Principle inspirations

Studied for *how they think*, not what they look like:

- **Linear** — restraint as a feature; the product is the marketing.
- **Stripe** — documentation as a designed surface; every example runnable.
- **Teenage Engineering** — playfulness with engineering rigor underneath.
- **Are.na / Cosmos** — collecting as a creative act; the moodboard as tool.
- **Gumroad** — brutalist-pop done with total commitment.
- **Vercel** — dark minimalism that never mistakes empty for elegant.
- **Raycast** — keyboard-first density without visual noise.
- **The Swiss school** (Müller-Brockmann et al.) — the grid is a moral position.
