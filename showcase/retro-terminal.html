# COMMAND REFERENCE

shipit deployBundle, preview, and promote. Flags: --prod, --dry-run, --skip-tests (not recommended)
shipit rollbackBack to the last green build in one command. No incident channel required.
shipit logsTail production logs with [WARN] and [FAIL] highlighted. Pipe it anywhere.
shipit statusOne screen: builds, deploys, health. The whole dashboard, minus the dashboard.
