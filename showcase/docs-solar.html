Getting started

FernDB is an embedded document store for side projects. Five minutes from install to your first query — no cluster, no YAML, no ceremony.

Install#

One package, one binary. If you can run npm, you can run FernDB.

bash 
# install the fern cli (takes about four seconds)
npm install -g ferndb

# start a local database — yes, that is the whole command
fern start --data ./my-app.fern
Tip

FernDB keeps everything in a single file. Back it up the way you'd back up a diary — because to your app, that's what it is.

Your first query#

Queries are plain strings. FernDB parses them, plans them, and runs them against your file. Here is the canonical first query:

bash 
# seed some data (do it, you'll feel productive)
fern insert users --name "ada" --plan "free"

# ask for it back — be nice, it's doing its best
fern query "users where plan = 'free'"

# → 1 result in 0.003s. frame it.

Next steps#

  1. Model your data. Collections are schemaless until you say otherwise — add a schema when the shape settles, not before.
  2. Wire up the driver. Official drivers for Node, Python, and Go; the REST API covers everything else.
  3. Ship it. The same file format runs on your laptop and in production. Copy the file, start the binary, done.
