# Y2K Chrome

> Liquid metal, iridescent gradients, bubbly type. The future as imagined in 1999.

## Tokens

| Token | Value | Role |
|---|---|---|
| `--bg` | `#0d0d12` | Deep space black-blue |
| `--surface` | `#15151d` | Lifted panels |
| `--ink` | `#f4f4f8` | Chrome white |
| `--muted` | `#6e6e80` | Muted lavender-gray |
| `--accent` | `#b8c5ff` | Iridescent periwinkle — glows, gradients |
| `--accent-2` | `#ffb8e6` | Bubblegum — gradient partner |
| `--line` | `#ffffff26` | Glassy rules |

## Type

- **Display:** Unbounded, rounded and futuristic, often with chrome gradient fill
- **Body:** Space Grotesk 400/500
- **Mono:** Space Mono for techy labels

Google Fonts: `Unbounded:wght@400;600;800` `Space+Grotesk:wght@400;500;700`
`Space+Mono:wght@400`

## Spacing & shape

- Chrome text recipe: `background: linear-gradient(180deg, #fff 20%, #b8c5ff 50%,
  #5a5a72 52%, #e8ecff 80%); -webkit-background-clip: text; color: transparent`.
- Radius: `24px+` — bubbles, pills, blobs. Everything is soft and inflated.
- Star sparkles (`✦` as SVG, never emoji) scattered sparingly.

## Motion

Floaty and glossy: slow bobbing, shine sweeps across chrome text on hover,
elastic cursor followers. Dreamy, not frantic.

## Do

- Iridescent gradient meshes (periwinkle → pink → mint)
- Inflated 3D-feeling buttons with inner highlights
- Pixel-star and bubble motifs as texture
- Throwback UI chrome: glossy toggles, gel buttons

## Don't

- No flat corporate minimalism — commit to the gloss
- No more than two gradient hues per viewport
- Keep body copy highly readable; the chrome stays in headlines

## The one weird thing

A Tamagotchi-style widget, a "desktop" section with draggable windows, or one
brutally honest low-fi element inside all the gloss.

## Best for

Beauty, pop culture, music, fashion, anything nostalgic-futurist.

## Pairs with patterns

`hero-kinetic`, `background-aurora`, `cards`, `marquee`
