# Swiss Poster

> Bold poster art: oversized type AS the image, flat color blocks, one
> accent. Shout it from the wall.

## Tokens

| Token | Value | Role |
|---|---|---|
| `--bg` | `#f2ede3` | Poster paper stock |
| `--surface` | `#e7e0d0` | Secondary paper panels |
| `--ink` | `#141414` | Poster black for all type |
| `--muted` | `#7a766c` | Stone gray, small print and dates |
| `--accent` | `#e8401f` | Signal red — ONE accent per poster, the shout |
| `--line` | `#141414` | Thick black rules and frames |

## Type

- **Display:** Archivo Black (as large as the layout allows — type IS the image, edge to edge)
- **Body:** Archivo (500, small, tight — dates, venues, practical info; the fine print is design too)
- **Mono:** Space Mono (catalog numbers, coordinates, ticket info)

Google Fonts: `Archivo+Black` `Archivo:wght@400;500;700`
`Space+Mono:wght@400;700`

## Spacing & shape

- Type fills the frame: headlines bleed to edges or stack floor-to-ceiling.
- Flat color blocks sit behind or between type — red, black, paper, never gradients.
- Radius: `0px`. Posters are cut, not rounded.
- Hierarchy through size and position only: the biggest word wins, the smallest word is still set with care.

## Motion

Bold and poster-like: type scales in with weight, color blocks wipe like ink
being rolled. Scrolling should feel like walking past a wall of wheat-pasted
posters — each section a new sheet. Fast, confident entrances; no float, no
fade-only timidity. Hover states invert colors instantly.

## Do

- Make the hero a single poster: one massive word or phrase, one accent block, the date.
- Stack type vertically for drama: line breaks are composition ("MUSIC / IN / THE / SQUARE").
- Use the signal red sparingly — one word, one block, one rule per poster. It shouts only when rare.
- Treat every section as its own poster with its own headline-as-image.

## Don't

- No photography as decoration — type is the image here (imagery only as flat duotone texture if at all).
- No multi-accent rainbows; one signal color plus black plus paper is the palette.
- No delicate small-type hero — if the headline fits comfortably, it's too small.
- No data grids, tables-as-layout, or systematic UI chrome — that's swiss-rational's job; this one is expressive.

## The one weird thing

Add one print-shop detail per page: a crop mark in the corner, a "Edition
300" numbering, or a misregistration-style double strike on one word (ink
offset by 2px, like a print error kept on purpose). Posters are printed things
— one production artifact makes it feel real. Pick one.

## Best for

Festivals, exhibitions, campaign launches.

## Lineage

The compositional boldness of mid-century poster design; the discipline of
saying one thing at maximum size; the beauty of flat ink on paper. Principles
only — 100% original implementation.
