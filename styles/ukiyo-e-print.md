# Ukiyo-e Print

> Japanese woodblock print: Prussian blue, vermillion, wave compositions.
> The floating world, keyed and registered.

## Tokens

| Token | Value | Role |
|---|---|---|
| `--bg` | `#f2ead8` | Washi paper |
| `--surface` | `#1b3a5c` | Prussian blue — full-bleed print blocks |
| `--ink` | `#1a2332` | Sumi ink, text and key-block lines |
| `--muted` | `#6f6a5c` | Stone gray, captions |
| `--accent` | `#c73e2e` | Vermillion — hanko seals, one wave crest |
| `--line` | `#1a233233` | Key-block hairlines (alpha allowed on lines) |

## Type

- **Display:** Shippori Mincho B1 (large; may run vertical inside cartouches, generous tracking, never hurried)
- **Body:** Zen Kaku Gothic New (1rem, quiet, unshowy)
- **Mono:** Space Mono (edition marks — "Ed. 12 / 50", dates)

Google Fonts: `Shippori+Mincho+B1:wght@400;700` `Zen+Kaku+Gothic+New:wght@400;500;700` `Space+Mono:wght@400;700`

## Spacing & shape

- Compositions are keyed like print blocks: a blue band, a paper margin, a red seal. Never a flat centered stack.
- Cartouche boxes frame headlines; vertical text columns where the content earns them.
- Radius: `0px`. The block is cut square.

## Motion

Tide-slow. Print blocks stamp in (opacity + tiny y shift, 500ms). Wave bands
drift horizontally on a long loop. Nothing bounces — the sea does not bounce.
With reduced motion, the print simply hangs on the wall.

## Do

- Stamp a vermillion hanko with the brand mark, slightly crooked, on every page.
- Frame the hero like a print: blue wave band, paper margin, red seal.
- Number editions: "No. 04 — the morning menu."
- Keep microcopy plain and true: "Noodles from 11. Broth till it's gone."

## Don't

- No gradients — color fields are flat, like ink pressed on paper.
- No rounded corners, no emoji icons — draw with key-block lines.
- No zen-empty minimalism for its own sake; that is a different DNA.
- No lorem. A print this deliberate says real things.

## The one weird thing

Each section carries a small registration mark — a crosshair `+` — in the
margin, in muted ink, as if the print is still being aligned. One per page.

## Lineage

The craft of Edo-period woodblock printing — key-block linework, registered
flat color fields, cartouche composition, the red seal as signature. Not ma-japanese:
this is woodblock craft — carved lines, stamped color, printed texture — where ma-japanese is zen minimalism — emptiness, quiet, restraint.
Principles only — 100% original implementation.
