# Cassette J-Card

> Photocopied liner notes, hand-labeled spines, tracklists typed with a tired ribbon.
> Side A still hits harder.

## Tokens

| Token | Value | Role |
|---|---|---|
| `--bg` | `#f2ede0` | J-card paper |
| `--surface` | `#e3dac2` | Folded-in panel, tray card |
| `--ink` | `#1e1c18` | Photocopy black |
| `--muted` | `#75705f` | Faded toner, secondary text |
| `--accent` | `#c2452d` | Tape-deck orange-red — labels, the record dot |
| `--line` | `#1e1c1826` | Hand-ruled lines (alpha allowed on lines) |

## Type

- **Display:** Archivo Black (uppercase — sharpie-on-the-label energy, 3–5rem)
- **Body:** Archivo (1rem, the typed thank-you list)
- **Mono:** Courier Prime (liner notes, running times — "Kitchen Radio — 3:42")

Google Fonts: `Archivo+Black` `Archivo:wght@400;500;700` `Courier+Prime:wght@400;700`

## Spacing & shape

- The page reads as an unfolded j-card: a horizontal spine strip runs full width with the title hand-set on it.
- Panels fold like the insert — front, spine, inside left, inside right.
- Tracklist tables with real running times; hand-ruled lines separate acts.
- Radius: `2px`. Photocopied paper, barely softened.

## Motion

Tracklist rows light up like a tape counter rolling (opacity only). The spine
strip nudges a few pixels on scroll (translate, transform only). With reduced
motion: the tape is stopped, everything readable.

## Do

- Write real track-style titles in examples: "Kitchen Radio", "Bus Fare", "Track 3 is the one."
- Break sections with "SIDE A" / "SIDE B" markers — they're the chapter titles.
- Hand-written correction styling for asides: a rotated note that says "dubbed twice, still good."
- Keep the record dot red and round, exactly once.

## Don't

- No purple or blue gradients — toner is black on paper, never a glow.
- No chrome skeuomorphism, no VHS static plastered over everything.
- No fake band names presented as real acts; write titles, not lies.
- No emoji, no lorem — liner notes are written by people.

## The one weird thing

A tape counter pinned in the header — "A 042" — that advances as you scroll
the page, set in mono. It counts nothing real and means everything.
