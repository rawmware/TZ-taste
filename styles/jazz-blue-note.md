# Jazz Blue Note

> Mid-century jazz sleeve art come to life: duotone photography, smoky blue-black, bold condensed sans shouting the session name, liner notes in two tight columns. This is the record, not the store.

## Type

- **Display:** Bebas Neue — the condensed session-title voice: huge, uppercase, tight leading. Titles stack like the famous sleeve mastheads.
- **Body:** DM Sans — liner notes: readable, two-column at desktop, justified like printed notes. Personnel lists, session dates, descriptions.
- **Mono:** Space Mono — catalog numbers, side/track listings, pressing info ("BLP 1537 · SIDE A"). Set in the accent orange for catalog codes.

Google Fonts: `Bebas+Neue`, `DM+Sans:opsz,wght@9..40,400;9..40,500`, `Space+Mono:wght@400;700`

## Spacing & shape

- Asymmetric sleeve composition: a big duotone image offset against stacked type, generous negative space — the classic cover balance.
- Hairline rules in smoke gray separate the notes section, like a printed inner sleeve.
- Corners square; this is printed cardboard, not glass.
- Track listings run in numbered mono columns — SIDE A / SIDE B.

## Motion

Restrained and cool: images crossfade, text reveals line by line like notes being read. A slow ken-burns drift on duotone hero images only. Hover states are simple brightness lifts on image, underline sweeps on links. Late-night tempo — nothing hurries.

## Do

- Duotone your imagery in the blue-note blue and black — one photograph treated this way carries the whole DNA.
- Stack the display type huge and condensed against the image; let the contrast do the drama.
- Write real liner notes: session personnel, recording dates, a quote from the night. Specificity is the aesthetic.
- Use the burnt orange strictly for catalog codes and the occasional rule — one warm note in the smoke.

## Don't

- Don't use full-color photography — the duotone treatment is what makes this mid-century, not the subject matter.
- Don't round or soften anything — this is sharp, printed, and square.
- Don't write jazz-cliché copy ("smooth", "sultry") — liner notes are technical and human, not perfume ads.
- Don't confuse this with the record-store DNA — there are no bins or stickers here; this is the artifact itself.

## The one weird thing

Give the hero the "cover treatment": the page hero IS an album cover — a square, duotone image with the stacked Bebas masthead and mono catalog code laid over it, and the site content starts below like an opened gatefold. Or add a side A/B toggle: content sections switch between two curated "sides" with a tactile flip control in mono. Pick one.
